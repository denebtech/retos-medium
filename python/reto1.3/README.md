# Reto 1.3: Contador de vocales y consonantes

Para nuestro último reto vamos a crear un contador de vocales y consonantes en un texto ingresado por el usuario.

## Requisitos

El reto consiste en contar la cantidad de ocurrencia de caracteres en un texto ingresado por el usuario para:

- Vocales (a, e, i, o, u)
- Consonantes (resto del abecedario)

Para añadir un poco de complejidad, mostraremos la cantidad de palabras, considerando válidas únicamente aquellas que contengan caracteres alfabéticos.
